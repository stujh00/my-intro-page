# 과제 8 · 카드 1 진행본

## 적용
기존 GitHub 저장소 루트에 이 압축파일 안의 파일을 덮어씁니다.
index.html, api/private.js, README-T08.md를 커밋하고 Vercel 배포 완료를 기다립니다.
프레임워크 설정은 Other, 출력 디렉터리는 기존 설정을 유지합니다.

## 카드 1 증빙
1. 공개 소개와 나만의 작업실이 함께 구분되는 화면을 캡처합니다.
2. 시크릿 창에서 /api/private를 열고 개발자 도구 Network에서 401과 응답 본문을 확인합니다.
예상 응답은 AUTH_REQUIRED입니다. 실제 배포 결과를 캡처하여 증빙합니다.

## 현재 범위
로그인이나 자료 조회 성공은 아직 구현하지 않았습니다.
현재 API는 모든 요청을 401로 거절하며, 패스키 검증을 흉내 내지 않습니다.
비공개 자료 세 항목은 다음 서버 저장 단계에서 계정별로 추가합니다.
공개 HTML이나 공개 정적 파일에 비공개 자료를 넣지 않습니다.

## 제출 전 검토
실제 이메일은 contact@example.invalid로 변경했습니다.
기존 사진과 LinkedIn 캡처는 유지했으므로 실제 개인정보 제외 조건에 맞게 최종 제출 전 검토해야 합니다.
